If you receive an error during development/debugging: Starting inspector on 127.0.0.1:9229 failed: address already in use

install lsof

$ apt update
$ apt install -y lsof

and kill the pid of port 9229

$ lsof -i :9229
$ kill -9 {pid}

## Architecture Notes

### Realtime Strategy (WebSockets)

This application uses an **Event-Driven Architecture**.
- **Events**: Generated by services and stored in the Redpanda/Kafka event bus.
- **Consumption**: The `UiGatewayModule` consumes relevant events and pushes them to connected UI clients.
- **Technology**: We use **Socket.io** (via `@nestjs/platform-socket.io`) for the UI connection.

**Important Configuration:**
GraphQL Subscriptions are explicitly **DISABLED** (`installSubscriptionHandlers: false`) in `app.module.ts`.
- **Reason**: Enabling them creates a conflicting WebSocket server (Apollo legacy subscription server) on the same port, which hijacks the connection upgrades and causes "Invalid frame header" errors for Socket.io clients.
- **Action**: Do not enable `installSubscriptionHandlers`. If you need to add GraphQL subscriptions in the future, you must configure them to run on a different port or path to avoid colliding with the Socket.io gateway.
